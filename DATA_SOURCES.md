# Data and method sources

The linked research records identify upstream context only. This repository
contains no study data, GWAS records, clinical records, or frozen study output.
It provides no downloader, access credential, or permission to redistribute
upstream data. Follow each provider's access, attribution and reuse terms
before obtaining or sharing its data.

- Metabolic-trait genetic resource: [Tambets et al., Nature](https://doi.org/10.1038/s41586-026-10532-5).
- FinnGen cohort resource: [Kurki et al., Nature](https://doi.org/10.1038/s41586-022-05473-8).
- Methodological context for summary-data multivariable MR under weak and
  pleiotropic instruments: [Sanderson, Spiller and Bowden](https://doi.org/10.1002/sim.9133).

The audit accepts already assessed regional rows. It does not compute
colocalization, infer outcome equivalence or participant overlap, or treat
posterior support under an input setting as proof of causation. Use only
authorized local inputs; the example and test data are synthetic.
